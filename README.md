# 🚀 Projetos em destaque

## 🛒 GVendix

Sistema acadêmico em desenvolvimento com foco em **Ponto de Venda (PDV) e comparação de preços**.

O projeto integra Frontend, Backend e banco de dados, utilizando autenticação e gerenciamento de usuários.

### Principais funcionalidades

- 👤 Cadastro e login
- 🔐 Autenticação com JWT
- 👤 Perfil do usuário
- ✏️ Edição de dados
- 🔑 Alteração de senha
- 🗑️ Exclusão de conta
- 🛒 Carrinho
- 💰 Comparação de preços
- 🌙 Tema claro e escuro
- ♿ Recursos de acessibilidade
- ✅ Validação de dados

### Tecnologias

`HTML5` `CSS3` `JavaScript` `Node.js` `Express.js` `MySQL` `JWT` `Bcrypt` `REST API`

🔗 **[Ver projeto no GitHub](https://github.com/GabrielaDias01/GVendixComparador)**
